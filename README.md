# Group 13 – Vehicle Detection

This project compares models for detecting, classifying and counting vehicles in drone images from the TRANSSET dataset.

- [Daniel](Daniel/) – YOLO training code and model setups.
- [Julius](Julius/) – Data cleaning, dataset splitting and Faster R-CNN.
- [Ruben](Ruben/) – RT-DETR training code.
- [Sandesh](Sandesh/) – Evaluation of three YOLO11s variants on 706 test images, including detection scores, counting errors and example images.

To run the YOLO11s evaluation, start with [Sandesh’s instructions](Sandesh/START_HERE.md).
